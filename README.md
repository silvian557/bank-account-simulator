# Banca George - Interactive Account Simulator

A complete Python console application that simulates an interactive banking registration process, featuring custom password validation, age-based account selection, and an initial deposit system.

## Features

- **Secure Password Validation:** Ensures the password isn't too simple (e.g., "1234") and doesn't match the user's birth year using `while` loops.
- **Password Confirmation:** Verifies that the confirmation password matches the initial choice.
- **Age & Account Verification:** Automatically calculates the user's age based on the current year and validates if they qualify for an adult or junior account.
- **Initial Deposit:** Allows users to optionally deposit money and check their final balance.

## How to Run

1. Make sure Python is installed on your computer (or use an online compiler).
2. Run the `banca_george.py` file.
3. Follow the interactive prompts in the terminal.
